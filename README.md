# GreenroomID

GreenroomID menyediakan layanan digital, Shop akun, dan akses Authenticator dalam satu situs.

## Fitur

- **Layanan:** ajukan request, pantau pekerjaan, dan kelola invoice serta formulir online.
- **Shop:** lihat produk dan lakukan pemesanan akun.
- **Authenticator:** akses kode TOTP.
- **Kilau AI:** segera hadir.

## Jalan lokal

1. Salin `.env.example` menjadi `.env.local`, lalu isi variabel yang diperlukan.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.

## Build

Jalankan `npm run build`. Skrip postbuild membuat halaman publik dan sitemap dari rute yang tersedia.
